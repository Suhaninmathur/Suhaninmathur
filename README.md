## 🚀 Projects

### 🛡️ Text Moderation System — Onyatrips
> A hybrid text moderation API that filters unsafe messages before they reach a chatbot.
- Built with **Python + Flask**
- Rule-based detection: phone numbers, emails, links, abusive language, spam
- AI moderation using **Groq (Llama 3)** for tone and toxicity analysis
- Returns structured decisions: allow / warn / flag / block

---

### 👥 Real-Time Crowd Detection System
> Live crowd monitoring system using computer vision.
- Built with **YOLOv8 + OpenCV** on live webcam feed
- Detects and counts people per frame with bounding boxes
- Triggers alerts based on crowd density thresholds
- Trained on **600 labeled images** with supervised learning

---

### 🔮 AstroVision — AI-Based Web Platform
> Modular AI web application for Vastu & Palm Analysis.
- Built **Python-based APIs** for rule-driven Vastu analysis
- AI-driven **chatbot logic** for contextual responses
- Palm-line detection using Python modelling workflow
- Responsive frontend with **HTML + CSS**
